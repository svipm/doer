## 本次更新

### 新增功能

**NewAPI 签到（站点中枢）**
- 站点预设与路由自动协商：new-api / Veloera / DoneHub / 通用，签到路由 404 时自动换用备用路由并记住结果
- 支持自建签到系统：自定义成功 / 已签到关键词判定，可编辑签到请求与附加请求头
- 「查看模型」：列出该账号在站点可用的模型，支持单个复制与复制全部
- 「用量」区块：余额、历史消耗、历史请求数（来自 `/api/user/self`）
- 内建浏览器自动探测 NewAPI 站点，命中后一键添加签到
- 后台自动签到：由系统择机唤醒执行（默认关闭，设置内开启）

**阅读**
- 阅读进度上报三态：实时（每 60 秒）/ 聚合（每 30 分钟合并为一个请求，显著减少触发 Cloudflare 验证）/ 关闭
- 楼层跳转一次到位：修复从 500 楼跳 120 楼时需要跳两次的问题

**底栏与通知**
- 底栏自定义：默认仅「首页 + 我的」，其余入口在 设置 → 底栏布局 中按需添加
- 通知文案修正：「新帖」实为关注话题的回复、「关注首帖」改为「分类新话题」，并补齐四语言翻译

**系统集成**
- 灵动岛 / 锁屏实时活动：批量签到时显示进度、成功 / 已签 / 失败计数（需 iOS 16.2+）
- Siri 与快捷指令：新增「打开稍后读」「打开通知」
- MetricKit 诊断采集：崩溃、卡顿、CPU / 磁盘异常与每日指标写入本地诊断日志

### 体验优化

- Cloudflare 挑战改为小窗过盾：半屏窗口（可上拉展开），不再全屏打断
- Cloudflare 挑战可**最小化**：收起后挑战在后台继续验证（挑战页保持在屏微窗口中运行），盾牌按钮可随时重新打开；验证通过后自动收尾
- 挑战页加载失败自动重试**修复并加强**：此前多次失败回调会耗尽重试次数却从未真正重新加载，现在每次重试都执行完整重载与状态重置，4 次退避（1.5s / 3s / 6s / 10s），页面开始加载即重置阶梯
- 进入帖子后底栏不再遮挡正文：修复滚动隐藏动画被打断后底栏卡住的竞态

### 问题修复

两轮全面排查共修复 20+ 处问题，主要项：

- **草稿**：三个编辑器的草稿保存原本是空实现，输入的回复 / 新帖 / 私信从未被保存；现已接通本地 + 服务器双写，发送成功与主动丢弃时正确清理
- **跳楼**：跳转失败不再白屏（恢复原窗口）；分页请求在跳转 / 过滤后不再污染列表
- **搜索**：修复快速连搜时旧结果覆盖新结果、翻页串台；瞬时错误不再永久禁用翻页
- **图片**：修复超时重拉时旧请求回调串台导致图片空白；头像不再用小图放大显示
- **网络与存储**：修复登录页 Cookie 观察者泄漏、WebView 请求缺少超时可挂死、Cookie 落盘竞态、Cookie 文件缺少文件保护
- **稳定性**：数据库损坏不再导致启动崩溃循环（损坏文件自动备份后重建）；阅读进度写入合并，长帖滚动不再卡顿
- **安全**：偏好备份导出前提示内含明文凭据并在分享后清理临时文件；拒绝 `http://` 明文论坛地址；登录 Cookie 域名匹配收紧
- **其他**：分享扩展主线程死等、书签翻页空转、稍后读重复请求、Cloudflare 回环 Cookie 残留、curl 导入输入上限等
